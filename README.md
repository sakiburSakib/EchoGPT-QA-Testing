# EchoGPT-QA-Testing

A Software Quality Assurance (SQA) testing portfolio for **EchoGPT – Multi AI Chat**, covering Chrome Extension testing, Android Application testing, API testing, bug reporting, exploratory testing, and UI/UX recommendations.

## Project Overview

The objective of this project is to evaluate the functionality, usability, and reliability of EchoGPT across its supported platforms and document the issues identified during testing.

## Testing Scope

### Chrome Extension
- Account registration and login
- Google and email authentication
- Logout and session behavior
- AI model selection and message handling
- Empty messages and character-limit handling
- Conversation context and chat history
- Settings and Dark Mode
- Floating text actions
- Webpage and text assistance

### Android Application
- Application launch
- Google and email authentication
- OTP verification
- Logout and session behavior
- AI chat and conversation context
- New Chat and chat history
- Model switching
- Network behavior
- Image and document features
- Application reopening and session persistence

### API Testing
- API request and response validation
- HTTP status code verification
- Request payload validation
- Error handling and negative testing
- Testing using Postman
